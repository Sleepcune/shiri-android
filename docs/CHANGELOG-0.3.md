# 拾日 0.3.0 更新说明

## 状态同步与导航

设置标题和页面内容由同一个 `ScreenKey` 派生，设置切换、连续进入、系统返回和回到对话首页不再使用旧页面内容。长任务在协程执行，保存设置先更新本地状态，再异步刷新提醒与组件。

## 待办与提醒

新增非重复待办延期、重复待办单次延期和独立“已过期”页签。待办通知包含“完成”动作，动作带任务版本和日期校验，失效时不会误改任务。提醒频道为高优先级并公开显示在锁屏；系统强制停止、关机和勿扰模式仍遵循安卓限制。

## 日报、饮食与账户

日报保存截止时刻和原始快照，支持历史查看、摘要、过时状态、重新生成和删除本地记录。餐食编辑可关联图库图片，分析在餐食详情保留完整文本，列表默认展示短摘要。账本显示所有已初始化账户的推算余额总计，同时提示未初始化账户数量。

## 课表与 AI

学期可自命名、独立切换并保留各自课程和外观。AI 对话上下文条数可在 1–20 间设置，默认 5 条；调休、补课、额外加课和单次调整的提示词与操作接口已明确区分。
