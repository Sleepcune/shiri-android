# 拾日 0.2.0 更新说明

发布日期：2026-10-08。保留 Hubra 的应用标识和发布签名，支持覆盖升级。

## 使用变化

应用更名拾日，采用蓝紫主题和日历／对话图标，提供自适应与单色图标。首页改为对话，四个主入口保留记账、课表和待办；今日总览移到对话顶部。设置按用途分组，系统返回回到进入前的页面。

对话结果显示具体新建内容或变更字段，待办详情增加历史。账户消费可按时间范围、分类和备注查看明细，退款独立统计。课表进入即显示网格，支持滑动切周、学期切换、冲突详情及每学期外观。

图片在应用私有目录分类管理，支持收藏、全屏查看、批量导出与删除，默认关闭自动清理。存储页分别显示照片、缓存和本机快照；删除图片保留饮食文字与账单。清除聊天保留业务记录，并停止所选待处理输入。

## 本轮反馈修复

- 六类桌面组件按可用高度计算容量；小尺寸保留课程、时间和教室，剩余项目以数量入口显示。
- 放假／补课采用整天业务操作，从原始安排取课，能够覆盖已有停课和错误调课；日期明确的过去补课也处理。
- 原始课表复制到目标日保留源日，只增加目标周安排。冲突明确报告，整体可撤销。
- 成功、部分完成、冲突和需补充不再重复使用“操作已保存”；输入异常和网络错误显示原因。
- 餐食字段兼容文字和菜品列表；格式不支持时指出具体字段，已保存账单保留，重试不重复创建同一账单。
- 读取响应体期间取消网络请求也会终止连接；清除或恢复之后的旧请求不能继续写入。
- 修复到点附近更新数据时取消待触发提醒的问题，保留当日仍有效的提醒并防止重复提交。
- 修复调课后课前提醒按原日期查课程的问题，改按实际上课日期定位；提醒状态增加权限、渠道、计划、触发和失败诊断，恢复权限后重排。

## 升级

1. 推荐先在旧版导出完整备份。
2. 安装 `Shiri-0.2.0-release.apk` 覆盖旧版，保持原有数据、API 密钥和组件实例。
3. 核对账户余额、当前学期和待办；现有图片自动补充分组，未知导入日期从升级整理时计算。
4. 可以重新发送原调休通知修正旧的单次调整；升级不会根据截图擅自修改你的真实课表。

自动验证与真机验证分别记录于 `VERIFICATION.md`。组件实际缩放、锁屏通知及真实 API 能力需要在真我 GT8 上确认。
